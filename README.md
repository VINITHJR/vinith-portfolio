# Vinith J R — Portfolio

A responsive React + Vite portfolio starter populated with the profile details shared in your PDF and project context.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code / terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

## Before publishing

- Replace the GitHub placeholder URL in `src/main.jsx` with your actual GitHub profile.
- Add project repository/demo links once you have public URLs.
- Check the wording and project status labels; update anything that has changed.
- Add a PDF resume link if you want a downloadable CV button.

## Build for deployment

```bash
npm run build
```

The production site is generated in `dist/`. Deploy it to Vercel, Netlify or GitHub Pages.
